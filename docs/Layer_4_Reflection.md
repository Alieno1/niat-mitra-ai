## 1. What's one thing you learned about yourself while doing this challenge?
I learned that I default to solving growth problems by inspecting the underlying system before brainstorming ideas. Instead of jumping straight into a generic AI chatbot, spending time reading NIAT’s live site structure, `/llm-info` guardrails, and affiliate terms revealed the real bottleneck—the 7-day post-NAT window and the Category-B consultant incentive clash. Once I saw the actual unit economics, building the solution became obvious. I also realized I work best when I ship end-to-end (database, tool-calling agent, and live UI together) rather than polishing slides, because seeing real data flow forces honest, practical product decisions. *(99 words)*
